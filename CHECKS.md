# Проверки проекта

Проведено 8 октября 2026 года в рабочей среде ChatGPT.

- строгая TypeScript-проверка собственного кода приложения через локальные декларации внешних UI-пакетов — пройдена;
- TypeScript-проверка `vite.config.ts` и генератора service worker — пройдена;
- генерация задач для четырёх сложностей — пройдена;
- проверка единственности решения — пройдена;
- стресс-проверка 48 разных сгенерированных задач — пройдена;
- проверка заметок, правильного и ошибочного хода, счёта, общей паузы и расчёта времени — пройдена;
- QR signaling round-trip: большой сигнал разбит на 17 кадров, принят в обратном порядке и восстановлен без потери данных — пройден;
- JSON-манифест PWA и размеры иконок 192×192, 512×512 и 180×180 — проверены;
- пользовательские строки дополнительно просмотрены на отсутствие шаблонных заголовков капсом.

## Что не удалось выполнить внутри этой среды

`npm install` не завершился, потому что контейнер не имеет рабочего доступа к npm registry. Из-за этого здесь не запускалась реальная Vite production-сборка с установленными Mantine/React/ZXing.

Для этой проверки в репозитории есть workflow `.github/workflows/deploy-pages.yml`: GitHub Actions устанавливает реальные зависимости, выполняет `npm run build` и публикует `dist` на GitHub Pages. Локально после `npm install` можно выполнить `npm run check`.

Физический сценарий iPhone ↔ Android также нужно проверить на двух настоящих устройствах: камера, ICE-кандидаты и доступ устройств друг к другу зависят от конкретных браузеров и Wi‑Fi сети.
